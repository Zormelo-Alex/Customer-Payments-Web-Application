# Payment Dashboard – Vendor Payment Viewer

## Overview

This project is a **React + TypeScript web application** that allows a shop vendor to **view and manage customer payment records**. The application integrates with the provided **Sales API** to retrieve payment history and display detailed payment information.

The dashboard presents payment data in a **clean, responsive table**, along with summary statistics and a detailed modal view for each payment.

This project was built using **React, TypeScript, Vite, and Tailwind CSS** with a focus on **good user experience, responsiveness, and clean code structure**.
